# Qorrax Solar ☀️

> **Clean energy. Simple future.**

Qorrax is a modern, responsive solar-energy landing page built with **HTML and CSS**. It presents a simple vision for making clean and reliable solar energy more accessible.

## ✨ Features

* Responsive modern UI
* Solar energy hero section
* Benefits and services
* Simple call-to-action
* Mobile-friendly design

## 🛠️ Built With

* HTML5
* CSS3
* Git & GitHub

## 🚀 Run Locally

```bash
git clone https://github.com/your-username/qorrax.git
cd qorrax
```

Open `index.html` in your browser.

This project was created as a **Git & GitHub Capstone** to practice commits, branches, pull requests, issues, code review, and GitHub Actions.
